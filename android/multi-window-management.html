多窗口管理 ​

本文介绍如何使用 WindowManager（多窗口管理器）功能，实现多应用窗口的管理和协作。

概述 ​

WindowManager 是 ScribbleForge SDK 提供的多窗口管理功能，允许在同一个房间内管理多个应用窗口（如白板、文档、幻灯片等）。每个窗口可以独立拖拽、缩放、最大化/最小化。

主要特性 ​

  • 多窗口管理：支持同时运行多个应用窗口
  • 窗口操作：支持拖拽、缩放、层级调整
  • 窗口状态：支持正常、最大化、最小化三种状态
  • 权限控制：支持用户权限管理
  • 自适应布局：支持设置宽高比和尺寸范围

初始化 WindowManager ​

1. 配置 WindowManagerOption ​

在创建 Room 时，配置 WindowManagerOption 来启用窗口管理功能：

kotlin
import io.agora.board.forge.RoomOptions
import io.agora.board.forge.windowmanager.WindowManagerOption

val roomOptions = RoomOptions(
    context = applicationContext,
    roomId = "YOUR_ROOM_ID",
    roomToken = "YOUR_ROOM_TOKEN",
    userId = "YOUR_USER_ID"
).apply {
    // 配置窗口管理器选项
    windowManagerOptions(
        WindowManagerOption(
            ratio = 16f / 9f,  // 窗口宽高比（可选）
            windowPosition = WindowManagerOption.WindowPosition(0.2f, 0.2f),  // 初始位置
            windowSize = WindowManagerOption.WindowSize(0.4f, 0.4f),           // 初始大小
            windowRange = WindowManagerOption.WindowRange(                     // 尺寸范围
                minWidth = 0.2f,
                minHeight = 0.2f,
                maxWidth = 0.8f,
                maxHeight = 0.8f
            )
        )
    )
}

2. 获取 WindowManager 实例 ​

在成功加入房间后，从 Room 实例中获取 WindowManager：

kotlin
room.joinRoom(object : RoomCallback<Boolean> {
    override fun onSuccess(result: Boolean) {
        // 获取 WindowManager 实例
        val windowManager = room.windowManager
        
        if (windowManager != null) {
            // 将 WindowManager 的视图添加到布局中
            val view = windowManager.getView()
            windowContainer.addView(view)
        }
    }
    
    override fun onFailure(error: RoomError) {
        Log.e("Room", "加入房间失败: ${error.message}")
    }
})

WindowManagerOption 配置说明 ​

参数详解 ​

参数类型说明默认值
ratioFloat?窗口宽高比，为 null 时不限制null
statusWindowStatus初始窗口状态NORMAL
windowPositionWindowPosition初始窗口位置（归一化坐标 0~1）(0.2, 0.2)
windowSizeWindowSize初始窗口大小（归一化坐标 0~1）(0.4, 0.4)
windowRangeWindowRange窗口大小范围限制(0.2~0.8, 0.2~0.8)

坐标系说明 ​

WindowManager 使用归一化坐标系统（0.0 ~ 1.0）：

  • 0.0 表示容器的起始位置（左边/顶部）
  • 1.0 表示容器的结束位置（右边/底部）
  • (0.5, 0.5) 表示容器的中心位置

示例：

kotlin
// 窗口位置在容器中心
WindowPosition(x = 0.5f, y = 0.5f)

// 窗口大小占容器的一半
WindowSize(width = 0.5f, height = 0.5f)

Application 管理 ​

WindowManager 内部维护一个独立的 ApplicationManager，用于管理窗口内的应用。

启动应用窗口 ​

使用 windowManager.launchApp() 启动一个新的应用窗口：

kotlin
// 启动白板窗口
windowManager?.launchApp(
    type = WhiteboardApplication.TYPE,
    option = WhiteboardOption(
        width = 1920,
        height = 1080
    ),
    appId = "whiteboard_1",           // 可选：应用 ID
    title = "我的白板",                // 可选：窗口标题
    callback = object : RoomCallback<Application<*>> {
        override fun onSuccess(result: Application<*>) {
            Log.i("WindowManager", "应用启动成功")
        }
        
        override fun onFailure(error: RoomError) {
            Log.e("WindowManager", "应用启动失败: ${error.message}")
        }
    }
)

Application 事件监听 ​

监听 WindowManager 中应用的生命周期事件：

kotlin
import io.agora.board.forge.ApplicationListener

windowManager?.addAppListener(object : ApplicationListener {
    override fun onAppLaunch(appId: String) {
        Log.i("WindowManager", "应用启动: $appId")
        
        // 获取应用实例
        val app = windowManager?.appManager?.getApp(appId)
        
        // 根据应用类型进行特定处理
        if (app is WhiteboardApplication) {
            app.setBackgroundColor(Color.WHITE)
        }
    }
    
    override fun onAppTerminate(appId: String) {
        Log.i("WindowManager", "应用终止: $appId")
    }
})

获取应用实例 ​

kotlin
// 获取指定应用
val app = windowManager?.appManager?.getApp("whiteboard_1")

// 获取所有应用
val apps = windowManager?.appManager?.getApps()

窗口状态管理 ​

窗口状态类型 ​

WindowManager 支持三种窗口状态：

状态说明
WindowStatus.NORMAL正常状态，窗口可自由拖拽和缩放
WindowStatus.MAXIMIZED最大化状态，窗口占满整个容器
WindowStatus.MINIMIZED最小化状态，窗口收起为图标

设置内容宽高比 ​

设置窗口内容的宽高比（影响所有窗口）：

kotlin
// 设置 16:9 宽高比
windowManager?.setContentRatio(16f / 9f)

// 取消宽高比限制
windowManager?.setContentRatio(null)

与主白板结合使用 ​

常见的使用场景是将主白板与 WindowManager 结合使用：

kotlin
class MyActivity : AppCompatActivity() {
    private lateinit var room: Room
    private var mainWhiteboard: WhiteboardApplication? = null
    private var windowManager: WindowManager? = null
    
    private fun setupRoom() {
        val roomOptions = RoomOptions(
            context = applicationContext,
            roomId = "room_id",
            roomToken = "room_token",
            userId = "user_id"
        ).apply {
            // 启用窗口管理器
            windowManagerOptions(WindowManagerOption(ratio = 16f / 9))
        }
        
        room = Room(roomOptions)
        
        // 监听主白板应用
        room.addAppListener(object : ApplicationListener {
            override fun onAppLaunch(appId: String) {
                if (appId == "main_whiteboard") {
                    mainWhiteboard = room.getApp(appId) as WhiteboardApplication
                    // 将主白板添加到布局
                    whiteboardContainer.addView(mainWhiteboard?.getView())
                }
            }
            
            override fun onAppTerminate(appId: String) {
                if (appId == "main_whiteboard") {
                    mainWhiteboard = null
                    whiteboardContainer.removeAllViews()
                }
            }
        })
        
        room.joinRoom(object : RoomCallback<Boolean> {
            override fun onSuccess(result: Boolean) {
                // 启动主白板
                launchMainWhiteboard()
                
                // 设置窗口管理器
                setupWindowManager()
            }
            
            override fun onFailure(error: RoomError) {
                Log.e("Room", "加入失败: ${error.message}")
            }
        })
    }
    
    private fun launchMainWhiteboard() {
        room.launchApp(
            type = WhiteboardApplication.TYPE,
            option = WhiteboardOption(width = 1920, height = 1080),
            appId = "main_whiteboard"
        )
    }
    
    private fun setupWindowManager() {
        windowManager = room.windowManager
        windowManager?.let { wm ->
            // 将窗口管理器视图添加到布局（在主白板上层）
            windowContainer.addView(wm.getView())
            
            // 监听窗口应用
            wm.addAppListener(object : ApplicationListener {
                override fun onAppLaunch(appId: String) {
                    Log.i("Window", "窗口应用启动: $appId")
                }
                
                override fun onAppTerminate(appId: String) {
                    Log.i("Window", "窗口应用关闭: $appId")
                }
            })
        }
    }
}

权限管理 ​

WindowManager 内置权限管理机制，只有具有操作权限的用户才能创建或关闭窗口。

权限类型 ​

权限说明
操作权限能够创建、关闭窗口
只读权限只能查看窗口，不能操作

检查和设置权限 ​

kotlin
// 检查当前用户是否有操作权限
val canOperate = windowManager?.permissionManager?.canOperate() ?: false

if (canOperate) {
    // 用户有权限，可以创建窗口
    windowManager?.launchApp(...)
} else {
    // 用户无权限
    Toast.makeText(this, "无操作权限", Toast.LENGTH_SHORT).show()
}

完整示例 ​

以下是一个完整的多窗口管理示例：

kotlin
class WindowManagerActivity : AppCompatActivity() {
    private lateinit var room: Room
    private var windowManager: WindowManager? = null
    
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_window_manager)
        
        setupRoom()
        setupUI()
    }
    
    private fun setupRoom() {
        val roomOptions = RoomOptions(
            context = applicationContext,
            roomId = Constants.ROOM_ID,
            roomToken = Constants.ROOM_TOKEN,
            userId = Constants.USER_ID
        ).apply {
            windowManagerOptions(
                WindowManagerOption(
                    ratio = 16f / 9f,
                    windowPosition = WindowManagerOption.WindowPosition(0.1f, 0.1f),
                    windowSize = WindowManagerOption.WindowSize(0.5f, 0.5f)
                )
            )
            socketProvider(RtmSocketProvider(rtmClient))
        }
        
        room = Room(roomOptions)
        
        room.joinRoom(object : RoomCallback<Boolean> {
            override fun onSuccess(result: Boolean) {
                initializeWindowManager()
            }
            
            override fun onFailure(error: RoomError) {
                showError("加入房间失败: ${error.message}")
            }
        })
    }
    
    private fun initializeWindowManager() {
        windowManager = room.windowManager
        
        windowManager?.let { wm ->
            // 添加视图
            findViewById<FrameLayout>(R.id.window_container).addView(wm.getView())
            
            // 监听应用事件
            wm.addAppListener(object : ApplicationListener {
                override fun onAppLaunch(appId: String) {
                    Log.i("WindowManager", "应用启动: $appId")
                }
                
                override fun onAppTerminate(appId: String) {
                    Log.i("WindowManager", "应用关闭: $appId")
                }
            })
            
            // 设置宽高比
            wm.setContentRatio(16f / 9f)
        }
    }
    
    private fun setupUI() {
        // 启动白板窗口
        findViewById<Button>(R.id.btn_launch_whiteboard).setOnClickListener {
            launchWhiteboardWindow()
        }
        
        // 启动文档窗口
        findViewById<Button>(R.id.btn_launch_doc).setOnClickListener {
            launchDocWindow()
        }
    }
    
    private fun launchWhiteboardWindow() {
        windowManager?.launchApp(
            type = WhiteboardApplication.TYPE,
            option = WhiteboardOption(width = 1920, height = 1080),
            appId = null,  // 自动生成 ID
            title = "白板",
            callback = object : RoomCallback<Application<*>> {
                override fun onSuccess(result: Application<*>) {
                    Toast.makeText(this@WindowManagerActivity, "白板启动成功", Toast.LENGTH_SHORT).show()
                }
                
                override fun onFailure(error: RoomError) {
                    showError("白板启动失败: ${error.message}")
                }
            }
        )
    }
    
    private fun launchDocWindow() {
        val images = arrayOf(
            ImageOption("https://example.com/page1.png", 800, 600),
            ImageOption("https://example.com/page2.png", 800, 600)
        )
        
        windowManager?.launchApp(
            type = ImageryDocApplication.TYPE,
            option = ImageryDocOption(
                images = images,
                displayMode = ImageryDocOption.DisplayMode.SINGLE
            ),
            title = "文档"
        )
    }
    
    override fun onDestroy() {
        super.onDestroy()
        room.leaveRoom()
    }
    
    private fun showError(message: String) {
        Toast.makeText(this, message, Toast.LENGTH_SHORT).show()
        Log.e("WindowManager", message)
    }
}

注意事项 ​

  1. 权限控制：确保用户有操作权限后再调用 launchApp() 和 terminalApp()
  2. 资源管理：及时关闭不需要的窗口，避免占用过多资源
  3. 视图层级：WindowManager 的视图应该在主白板视图之上
  4. 坐标归一化：所有位置和尺寸参数都使用 0~1 的归一化坐标
  5. 宽高比限制：设置 ratio 后，所有窗口会按照该比例显示
  6. 应用 ID 前缀：WindowManager 内的应用 ID 会自动添加 w_ 前缀

最佳实践 ​

  1. 合理规划布局：主白板和窗口管理器分层显示，避免遮挡
  2. 统一宽高比：为了更好的视觉效果，建议设置统一的宽高比（如 16:9）
  3. 权限提示：当用户无操作权限时，给予明确的提示信息
  4. 错误处理：妥善处理各种错误情况，提供友好的错误提示
  5. 性能优化：限制同时打开的窗口数量，避免性能问题
