权限控制 ​

本文介绍如何管理用户权限，包括白板权限和房间读写权限的设置和管理。

白板权限控制 ​

白板权限用于控制用户在白板上的操作能力，通过 WhiteboardPermission 类管理。

白板权限列表 ​

权限常量值说明
NONE0无任何权限，只能观看
DRAW1 << 0可以绘制元素
EDIT_SELF1 << 1可以修改自己创建的元素
EDIT_OTHERS1 << 2可以修改他人创建的元素
DELETE_SELF1 << 3可以删除自己创建的元素
DELETE_OTHERS1 << 4可以删除他人创建的元素
MAIN_VIEW1 << 5可以修改主视角、添加/删除页面
SET_OTHERS_VIEW1 << 6可以修改他人的视角模式
ALL全部位所有权限

设置白板权限 ​

kotlin
// 设置自己的权限
val permission = WhiteboardPermission(
    WhiteboardPermission.DRAW or 
    WhiteboardPermission.EDIT_SELF or 
    WhiteboardPermission.DELETE_SELF
)
whiteboardApp.setPermission(null, permission)

// 设置其他用户的权限
val permission = WhiteboardPermission(WhiteboardPermission.DRAW)
whiteboardApp.setPermission("user_123", permission)

// 设置为只读（无任何权限）
whiteboardApp.setPermission("user_456", WhiteboardPermission(WhiteboardPermission.NONE))

// 设置所有权限
whiteboardApp.setPermission(null, WhiteboardPermission(WhiteboardPermission.ALL))

添加权限 ​

kotlin
// 添加单个权限
whiteboardApp.addPermission(null, WhiteboardPermission.DRAW)

// 添加多个权限
whiteboardApp.addPermission(
    null, 
    WhiteboardPermission.DRAW or WhiteboardPermission.EDIT_SELF
)

// 为其他用户添加权限
whiteboardApp.addPermission("user_123", WhiteboardPermission.MAIN_VIEW)

移除权限 ​

kotlin
// 移除单个权限
whiteboardApp.removePermission(null, WhiteboardPermission.DRAW)

// 移除多个权限
whiteboardApp.removePermission(
    null,
    WhiteboardPermission.EDIT_OTHERS or WhiteboardPermission.DELETE_OTHERS
)

// 移除其他用户的权限
whiteboardApp.removePermission("user_123", WhiteboardPermission.MAIN_VIEW)

获取权限 ​

kotlin
whiteboardApp.getPermission(null, object : RoomCallback<WhiteboardPermission> {
    override fun onSuccess(result: WhiteboardPermission) {
        val flags = result.getFlags()
        Log.d("Permission", "当前权限: $flags")
        
        // 检查是否有特定权限
        if (result.has(WhiteboardPermission.DRAW)) {
            Log.d("Permission", "有绘制权限")
        }
        
        if (result.has(WhiteboardPermission.MAIN_VIEW)) {
            Log.d("Permission", "有主视图权限")
        }
    }
    
    override fun onFailure(error: RoomError) {
        Log.e("Permission", "获取权限失败: ${error.message}")
    }
})

// 获取其他用户的权限
whiteboardApp.getPermission("user_123", callback)

监听权限变化 ​

kotlin
whiteboardApp.addListener(object : SimpleWhiteboardListener() {
    override fun onPermissionUpdate(
        whiteboard: WhiteboardApplication,
        userId: String,
        value: WhiteboardPermission
    ) {
        Log.d("Permission", "用户 $userId 权限更新: ${value.getFlags()}")
        
        // 根据权限更新 UI
        updateUIBasedOnPermission(userId, value)
    }
})

房间读写权限 ​

房间级别的读写权限控制用户是否能够修改白板内容。

设置读写权限 ​

kotlin
// 设置自己为可写
room.setWritable(writable = true, callback = object : RoomCallback<Boolean> {
    override fun onSuccess(result: Boolean) {
        Log.d("Writable", "设置成功: 可写=$result")
    }
    
    override fun onFailure(error: RoomError) {
        Log.e("Writable", "设置失败: ${error.message}")
    }
})

// 设置其他用户为只读
room.setWritable(userId = "user_123", writable = false, callback)

获取读写权限 ​

kotlin
// 获取自己的权限
val isWritable = room.isWritable()
Log.d("Writable", "当前用户可写: $isWritable")

// 获取其他用户的权限
val userWritable = room.isWritable("user_123")
Log.d("Writable", "用户 user_123 可写: $userWritable")

监听读写权限变化 ​

kotlin
room.addWritableListener(object : WritableListener {
    override fun onWritableChanged(userId: String, writable: Boolean) {
        Log.d("Writable", "用户 $userId 可写状态变化: $writable")
        
        // 更新 UI
        updateUserWritableStatus(userId, writable)
    }
})

注意事项 ​

  1. 权限层级：房间读写权限是白板权限的前提，只读用户即使有白板权限也无法操作
  2. 权限同步：权限设置会自动同步到所有用户
  3. 默认权限：新加入的用户默认拥有所有白板权限和可写权限
  4. 权限检查：在执行敏感操作前，建议先检查用户权限
  5. 位运算：白板权限使用位运算组合，可以灵活设置多个权限

权限组合示例 ​

kotlin
// 基础编辑权限（可绘制、编辑和删除自己的内容）
val basicPermission = WhiteboardPermission(
    WhiteboardPermission.DRAW or
    WhiteboardPermission.EDIT_SELF or
    WhiteboardPermission.DELETE_SELF
)

// 管理员权限（可编辑和删除所有内容）
val adminPermission = WhiteboardPermission(
    WhiteboardPermission.DRAW or
    WhiteboardPermission.EDIT_SELF or
    WhiteboardPermission.EDIT_OTHERS or
    WhiteboardPermission.DELETE_SELF or
    WhiteboardPermission.DELETE_OTHERS or
    WhiteboardPermission.MAIN_VIEW or
    WhiteboardPermission.SET_OTHERS_VIEW
)

// 主持人权限（可以管理页面和他人视角）
val moderatorPermission = WhiteboardPermission(
    WhiteboardPermission.DRAW or
    WhiteboardPermission.EDIT_SELF or
    WhiteboardPermission.DELETE_SELF or
    WhiteboardPermission.MAIN_VIEW or
    WhiteboardPermission.SET_OTHERS_VIEW
)
