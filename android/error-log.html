SDK 日志 ​

本文介绍如何配置和获取 ScribbleForge SDK 日志。

日志配置 ​

默认情况下，SDK 日志会保存到应用的缓存目录下，文件名格式为 forge_logs_<timestamp>.log，默认等级为 INFO。你可以通过配置 LoggerOptions 来自定义日志的保存路径和级别。

基本配置 ​

kotlin
import io.agora.board.forge.RoomOptions
import io.agora.board.forge.LoggerOptions
import io.agora.board.forge.LogLevel

val roomOptions = RoomOptions(
    context = applicationContext,
    roomId = "YOUR_ROOM_ID",
    roomToken = "YOUR_ROOM_TOKEN",
    userId = "YOUR_USER_ID"
).apply {
    // 配置日志选项
    val logOptions = LoggerOptions().apply {
        // 设置日志文件保存路径（可选）
        filePath = externalCacheDir?.absolutePath
        
        // 设置日志级别（可选）
        level = LogLevel.DEBUG
    }
    loggerOptions(logOptions)
}

日志级别 ​

SDK 支持以下日志级别，按严重程度从低到高排列：

级别说明使用场景
LogLevel.DEBUG调试级别开发调试时使用，包含详细的调试信息
LogLevel.INFO信息级别默认级别，记录一般性信息
LogLevel.WARN警告级别记录警告信息，表示潜在问题
LogLevel.ERROR错误级别仅记录错误信息

配置示例 ​

开发环境配置（详细日志） ​

kotlin
val logOptions = LoggerOptions().apply {
    filePath = context.externalCacheDir?.absolutePath
    level = LogLevel.DEBUG  // 开发时使用 DEBUG 级别
}

生产环境配置（精简日志） ​

kotlin
val logOptions = LoggerOptions().apply {
    filePath = context.filesDir.absolutePath
    level = LogLevel.INFO  // 生产环境使用 INFO 级别
}

最小日志配置 ​

kotlin
val logOptions = LoggerOptions().apply {
    level = LogLevel.ERROR  // 仅记录错误
}

获取本地日志 ​

使用 ADB 命令

使用以下 ADB 命令获取日志文件。需要将 {应用包名} 替换为你的应用包名，例如 io.agora.board.forge.sample。

shell
adb pull /sdcard/Android/data/{应用包名}/cache/forge_logs .

日志分析建议 ​

查找关键信息 ​

  1. 加入房间流程：搜索 joinRoom
  2. 应用启动：搜索 launchApp
  3. 错误信息：搜索 ERROR
  4. 连接状态：搜索 onStateChanged

常见日志标签 ​

标签说明
[Room]房间相关操作
[AppMgr]应用管理相关
[WindowMgr]窗口管理相关
[DocMgr]文档管理相关

注意事项 ​

  1. 存储权限：使用外部存储路径时，需要确保应用有相应的存储权限
  2. 日志大小：长时间运行可能产生大量日志，建议定期清理
  3. 隐私安全：日志中可能包含敏感信息，分享时需注意脱敏处理
  4. 性能影响：DEBUG 级别会产生大量日志，可能影响性能，生产环境建议使用 INFO 或更高级别
