多窗口管理 ​

本文概述 ScribbleForge 的多窗口系统，用于承载白板、幻灯片、播放器等应用的窗口化管理：初始化与布局、容器挂载、窗口操作、权限控制与回调。

初始化与布局配置 ​

WindowManagerOption（在 JoinRoomOptions(windowManagerOption:) 里传入）可配置窗口初始行为：

  • windowSize: 初始窗口大小（比例）
  • windowPosition: 初始窗口位置
  • windowMinSize / windowMaxSize: 允许的窗口最小/最大比例
  • ratio: 容器内容宽高比（可运行时 updateRatio 更新）
  • permission: 初始窗口管理权限（WindowManagerPermission，常用位 .operating）

示例：

swift
let wmOption = WindowManagerOption(
    windowSize: CGSize(width: 0.4, height: 0.4),
    windowPosition: CGPoint(x: 0.1, y: 0.1),
    windowMinSize: CGSize(width: 0.3, height: 0.3),
    windowMaxSize: CGSize(width: 1.0, height: 1.0),
    ratio: 16.0/9.0,
    permission: [.operating]
)

let options = JoinRoomOptions(
    writable: true,
    authOption: auth,
    windowManagerOption: wmOption
)

容器挂载与自动运行 ​

swift
// 已完成 RTM 登录，并 joinRoom 成功
if let container = room.windowManager.applicationView {
    container.frame = hostView.bounds
    hostView.addSubview(container)   // 将多窗口容器挂到宿主界面
}
// join 成功后 WindowManager 会自动 run

功能概览 ​

  • 多应用、多实例窗口化：白板、幻灯片、播放器等都以窗口形式呈现。
  • 窗口状态：normal / minimized / maximized，对应 UI 操作按钮。
  • 焦点与层级：focusApp 将窗口置顶并触发焦点回调。
  • 拖动与布局：窗口支持拖动移动，初始位置/尺寸可配置。
  • 工具栏与最小化区域：主视图包含工具栏，最小化窗口可从悬浮按钮恢复。
  • 权限控制：通过 WindowManagerPermission（如 .operating）决定是否允许拖拽、聚焦、最小化/最大化等操作。
  • 自适应布局：可配置容器比例 ratio 与窗口最小/最大比例，结合运行时 updateRatio 适配不同屏幕和方向。***

回调（WindowManagerDelegate） ​

  • permissionUpdate：窗口管理权限更新
  • windowStateUpdate：窗口状态变化（maximized / minimized / normal）
  • focusedAppUpdate：焦点窗口变更
  • didLaunchApp / didTerminal：窗口化应用启动/关闭

启动窗口化应用 ​

swift
// 示例：启动白板窗口
room.windowManager.launchWhiteboard(
    option: .init(width: 1920, height: 1080)
) { result in
    if case .success(let whiteboard) = result {
        whiteboard.delegate = self
    }
}
// 其它：launchSlide / launchImageDoc / launchMediaPlayer

窗口操作 ​

swift
// 切换窗口状态（等同于 UI 按钮）
room.windowManager.updateWindowState(.maximized)   // .normal / .minimized / .maximized

// 聚焦窗口（置顶）
room.windowManager.focusApp(appId)

// 移动窗口位置
room.windowManager.moveApp(appId, to: CGPoint(x: 120, y: 80))

// 终止窗口化应用
room.windowManager.terminalApp(appId)

权限 ​

WindowManagerPermission 为 OptionSet，当前常用位：.operating。权限变更会通过 permissionUpdate 回调告知：

swift
// 设置/查询权限（按用户）
room.windowManager.setPermission(userId, permission: [.operating])
let p = room.windowManager.getPermission(userId)

当用户拥有 .operating 时，可拖动、聚焦、最小化/最大化窗口。

注意事项 ​

  • room.joinRoom 成功后 WindowManager 自动运行；
  • 权限与房间可写状态相关，运营策略可通过 WindowManagerPermission 控制用户的窗口操作能力；
