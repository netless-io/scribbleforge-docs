互动白板 ​

本文概述 ScribbleForge 白板在 iOS 的常见用法：

启动白板与挂载视图 ​

swift
// 已完成 RTM 登录，并 joinRoom 成功
room.launchWhiteboard(
    option: .init(
        width: 1920,
        height: 1080,
        maxScaleRatio: -1,               // -1 表示无边界
        defaultToolInfo: .init(
            tool: .selector,
            strokeColor: "#1f6bff",
            strokeWidth: 2
        ),
        stretchToFill: false             // 是否拉伸填充容器
    )
) { result in
    if case .success(let whiteboard) = result {
        whiteboard.delegate = self               // 遵循 WhiteboardDelegate
        if let view = whiteboard.applicationView {
            view.frame = hostView.bounds
            hostView.addSubview(view)    // 将白板视图直接挂到宿主界面
        }
    }
}

WhiteboardInitializeOption 要点：

  • width/height: 白板可视区域基准尺寸，所有端需一致。
  • maxScaleRatio: 视口最大缩放倍数，-1 表示无限制。
  • defaultToolInfo: 默认工具/字号/颜色等。
  • stretchToFill: 是否拉伸白板区域填满容器。

回调（WhiteboardDelegate） ​

  • whiteboardElementSelected / Deselected
  • whiteboardToolInfoUpdate
  • whiteboardPageInfoUpdate(activePageIndex, pageCount)
  • whiteboardUndoStackLengthUpdate / RedoStackLengthUpdate
  • whiteboardPagePermissionUpdate(userId, permission)
  • whiteboardError(errorCode, errorMessage)

常用 API（Whiteboard） ​

工具与样式 ​

swift
whiteboard.setCurrentTool(.curve)
whiteboard.setStrokeColor(UIColor(hex: "#ff7a00"))
whiteboard.setFillColor(UIColor(hex: "#ffeecc"))
whiteboard.setStrokeWidth(4)
whiteboard.setFontSize(20)
whiteboard.setDashArray([4, 2])                 // 虚线样式

视图模式与权限 ​

swift
whiteboard.setViewMode(.mainView)               // .free / .mainView / .follow(userId:)
let mode = whiteboard.getViewMode()

let p = whiteboard.getPermission()              // WhiteboardPermission (OptionSet)
whiteboard.setPermission(permission: [.draw, .erase])

画布与元素 ​

swift
whiteboard.translateCamera(offset: CGPoint(x: 100, y: 0))
whiteboard.scaleCamera(scale: 1.2)
whiteboard.resetCamera()

let remoteURL = URL(string: "https://example.com/example.png")!
whiteboard.insert(image: remoteURL)             // 图片插入
whiteboard.setElementAttribute(
    layerId: "layer-1",
    elementId: "elem-1",
    attributeKey: .locked,
    value: true
)

insert(image:) 最终会透传到底层白板内核加载资源，建议使用可访问的 https 图片 URL。更完整的参数说明见 Whiteboard API 文档。

导出 / 截图 ​

swift
// 导出页面栅格图
whiteboard.rasterize(.viewport(page: nil, scale: 1.0)) { result in
    // 参见回调体实现（调用 bridge 返回）
}

页面导航（IndexedNavigation） ​

swift
whiteboard.indexedNavigation.pageCount { count in }
whiteboard.indexedNavigation.currentPageIndex { index in }
whiteboard.indexedNavigation.pushPage(goto: true)
whiteboard.indexedNavigation.insertPage(after: 2)
whiteboard.indexedNavigation.nextPage()
whiteboard.indexedNavigation.prevPage()
whiteboard.indexedNavigation.gotoPage(index: 5)
whiteboard.indexedNavigation.removePage(index: nil)   // nil 表示当前页

Undo / Redo ​

swift
whiteboard.undo()
whiteboard.redo()

销毁 ​

swift
whiteboard.terminal()              // 关闭白板

注意事项 ​

  • 各端 WhiteboardInitializeOption 的 width/height/maxScaleRatio 应保持一致，以避免各端显示内容不一致。
  • 需在 room.joinRoom 成功后再启动白板，并将 whiteboard.applicationView 挂到宿主视图。
  • 白板权限依赖房间内的可写状态和白板自身权限设置；
