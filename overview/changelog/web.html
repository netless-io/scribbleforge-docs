Web 端更新日志 ​

v1.3.0 (2026-06-09) ​

  • @netless/forge-room、@netless/forge-whiteboard、@netless/forge-imagery-doc、@netless/forge-slide 正式发布 1.3.0。
  • 稳定支持 pageId 页面管理能力：addPage、gotoPage、deletePage、pageList、currentPageId。
  • Whiteboard.insertImage 支持 pageId、fit、role options，可用于指定插入页面、适配方式和背景图角色。
  • IndexedNavigation bridge handler 对齐 whiteboard.indexed* 命名，提升 Web / JSBridge / Native 跨端一致性。
  • 对齐 snapshot 上传策略：基于当前 live docs 全量构建 snapshot，避免上传内容长期停留在历史状态。
  • 提升 join 阶段同步稳定性：subdoc 远端更新在 @room/subDocs 未就绪时先缓存后重放，减少 join 中同步消息漏处理的问题。

v1.3.0-beta.1 (2026-05-19) ​

  • Whiteboard.insertImage 支持 fit 配置，可用于控制插入图片的适配方式。
  • 优化白板背景图与 IndexedNavigation 页面导航处理，提升背景图和翻页场景的稳定性。
  • 优化 ReplayPlayer 时间线与白板渲染处理。
  • 修复绘制曲线过程中清空页面可能导致异常或残留的问题。
  • 补充背景图与 IndexedNavigation 相关测试覆盖。

v1.2.1 (2026-05-27) ​

  • 修复 room 初始化向量同步稳定性问题，降低多人加入或恢复时的数据同步异常风险。
  • 延续 1.3.0-beta.1 中的白板背景、页面导航、插图适配和清空绘制中曲线相关修复。

v1.2.0 (2026-05-26) ​

  • 加强入房与快照恢复稳定性：joinRoom 区分 404 / 5xx 场景，404 自动走 fullRoomExchange 兜底，避免重复 initVector 交换。
  • 优化数据交换策略：优先从 writable peers 同步，限制 peer 数与超时时间，降低大房间同步抖动。
  • writable 切换为 readonly 时立即强制上传快照，减少只读用户恢复不完整的情况。
  • conflictV2 支持 forge-room-doc 主文档，冲突恢复覆盖更完整。
  • 重构 Metrics/WhiteTracker 上报链路，统一按 60 秒聚合上报 sendRate、conflict、fps、snapshot 等指标。
  • 指标增强：补充 Snapshot 成功率与平均耗时，FPS 增加 P90 百分位，且 dev/private 区域不再上报。
  • 新增 ReplayPlayer 虚拟时钟回放能力，并补强 window manager 初始化与回放时序。
  • 修复 Apple Pencil 手掌误触导致笔迹中断的问题。
  • 优化曲线笔迹质量与缩放场景下的书写一致性，减少缩放后笔迹表现失真。
  • 插入图片时自动按当前视口居中并按比例适配展示。
  • 点文本初始化流程优化，避免首次创建时 points 重复设置。
  • 图片渲染与截图流程增加跨域处理和错误兜底，提升导出稳定性。
  • 修复 logger 生命周期重复创建/释放问题，释放 Room 实例计数，提升多次进出房间稳定性。
  • 新增并完善 snapshot strategy、conflict-room-doc、metrics 等 Playwright/E2E 测试覆盖。

v1.2.0-beta.3 (2026-05-11) ​

  • 移除曲线压感点异常影响，提升白板曲线绘制稳定性。
  • 优化文本点初始化逻辑，避免 point text 初始化时重复设置 points。
  • 作为 JSBridge / Native 同步基线，供 Android 与 iOS 内嵌资源对齐。

v1.1.2 (2026-04-01) ​

指标上报重构 ​

  • 所有质量指标改为通过 WhiteTracker 上报（替代 log），POST 到统一的指标收集端点
  • 所有周期性指标统一为每 60 秒聚合上报一次，大幅减少日志量
    • 消息发送速率（sendRate）：1s → 60s
    • 冲突次数 / 解决耗时（conflict）：事件驱动 → 60s 聚合
    • FPS：~5s → ~60s，新增 P90 百分位
    • Snapshot 上传：每次即时上报 → 60s 聚合，包含成功率和平均耗时
  • WhiteTracker 去除 white-sdk 依赖（createWhiteBasicTags），OS 从 userAgent 提取
  • WhiteTracker 删除内置 FPS 统计，统一由白板渲染层上报
  • dev / private region 不上报指标数据

joinRoom 稳定性改进 ​

  • Snapshot 服务端 5xx 错误时直接抛出 SNAPSHOT_SERVER_ERROR，不再静默失败
  • Snapshot 404 时自动走 fullRoomExchange 兜底，从在线用户同步数据
    • writable 用户优先选择，最多 10 peers，3000ms 超时
    • 兜底完成后跳过 Step 8 initVector，避免重复数据交换
  • writable → readonly 切换时立即 force putSnapshot，防止数据丢失
  • conflictV2 支持 forge-room-doc，room 主文档也能参与冲突响应

白板体验优化 ​

  • 修复 Apple Pencil 手掌误触导致笔迹中断的问题
  • 优化曲线笔迹质量，支持真实 Apple Pencil 压感
  • 缩放感知的 perfect-freehand 参数，笔迹粗细跟随 zoom 变化
  • WhiteboardTool 基类增加拖拽事件节流，减少高频事件开销

其他 ​

  • 新增 ReplayPlayer 虚拟时钟回放功能
  • 新增 joinRoom 分阶段计时，各步骤耗时随日志上报
  • 新增 Metrics 指标统计类（gauge / count / start 语义）
  • 新增 playwright e2e 测试覆盖 snapshot strategy、conflict-room-doc、metrics 上报
