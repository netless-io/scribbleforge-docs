Android 端更新日志 ​

[1.3.0] - 2026-06-09 ​

  • 更新内嵌 ForgeJS 至 1.3.0。
    • 同步 1.3.0 正式版页面管理能力，稳定支持 addPage、gotoPage、deletePage、pageList、currentPageId。
    • WhiteboardApplication.insertImage 支持 Web 兼容的 pageId、fit、role options。
    • IndexedNavigation bridge handler 对齐 Web 命名，提升跨端一致性。
  • 增加 Forge Room 回调日志，便于排查房间事件与状态流转问题。

[1.3.0-beta.1] - 2026-05-20 ​

  • 同步 Web 1.3.0 白板 pageId API 命名，新增 addPage、gotoPage、deletePage、pageList、currentPageId。
  • WhiteboardApplication.insertImage 支持 Web 兼容的 pageId、fit、role options，并保留 insertImage(src, pageId) 兼容调用。
  • IndexedNavigation bridge handler 切换到 whiteboard.indexed* 命名，Native IndexedNavigation 公共接口保持不变。
  • Demo 增加页面管理入口与 addPage + insertImage + gotoPage + delete 组合测试。
  • 增加 WhiteboardApplication 与 IndexedNavigation 页面语义基础集成测试。

[1.2.1] - 2026-05-27 ​

  • 更新 内嵌 ForgeJS 至 1.2.1。
    • 修复加入房间时偶现的数据重复或错乱问题，提升多人同步稳定性。
    • 修复绘制曲线过程中清空页面可能导致异常或笔迹残留的问题。
    • 增强页面导航容错能力，避免异常页面数据导致白板不可用。

[1.2.0] - 2026-05-11 ​

  • 更新 内嵌 ForgeJS 至 1.2.0。
    • 同步 Whiteboard 相关修复，移除曲线压感点带来的异常影响。
    • 同步 Whiteboard 文本点初始化优化，提升绘制稳定性。
  • 新增 WhiteboardApplication.insertImage 方法，支持在白板上插入图片。

[1.1.3] - 2026-04-16 ​

  • 更新 内嵌 ForgeJS 至 1.1.4。
  • 修复 房间加入完成前注册消息监听导致的时序问题。

[1.1.2] - 2026-04-01 ​

  • 修复关键状态变更后快照未及时上传，导致后续恢复状态不完整的问题。
  • 修复服务端快照不存在时加入房间可能恢复失败的问题。

[1.1.1] - 2026-01-28 ​

  • 新增 WhiteboardApplication.setPerformanceMode 动态设置性能模式。

[1.1.0] - 2025-12-24 ​

  • 修复 白板绘制时偶现画笔涂层错位问题

[1.1.0-beta03] - 2025-12-10 ​

  • 修复 SlideApp 缩略图显示异常问题
  • 新增 RoomErrorCode.ROOM_SNAPSHOT_RESTORE_FAILED 错误处理
  • 新增 RoomOptions.timeout 配置项，支持自定义房间连接超时时间

[1.1.0-beta02] - 2025-12-05 ​

  • 新增 只读可写（Writable）能力
  • 优化 只读模式的冲突处理逻辑，提升整体稳定性
  • 优化 窗口管理（层级、缩放、最大化等）
  • 修复 多项边界问题并提升测试覆盖率
  • 新增 Demo 中的权限与可写模式示例

[1.0.4] - 2025-11-27 ​

  • 修复偶现数据错乱问题

[1.0.3] - 2025-09-10 ​

  • 修复冲突处理逻辑异常，避免出现错误的数据交换
  • 修复多窗口场景偶现不同步

[1.0.2] - 2025-08-10 ​

  • 修复多窗口下退出时的错误
  • 修复加入房间时偶现的数据不一致问题

[1.0.1] - 2025-08-19 ​

  • 修复 兼容低版本 Android WebView（ES5）
  • 修复 历史记录记录错误
  • 新增 更多日志信息

[1.0.0] - 2025-07-24 ​

  • 修复 离线用户信息导致的白板应用无法绘制
  • 支持 16 KB 的页面大小

[1.0.0-alpha01] - 2025-07-16 ​

  • 新增 WindowManager 支持
  • 新增 SlideApplication 支持, 用于幻灯片应用。
  • 新增 ImageryDocApplication 支持, 用于图像文档应用。
  • BREAKING CHANGE: 与 0.1.x 内部数据不兼容，需要强制升级。

[0.1.13] - 2025-06-12 ​

  • 修复退出前清理白板应用不生效问题。

[0.1.12] - 2025-06-04 ​

  • 新增 WhiteboardApplication.updateViewport 方法，布局变更时候更新白板视图区域。
  • 新增 Application.performPrivateFunction 方法，允许调用部分私有方法。
  • 支持设置主画布可见性。 例如 whiteboardApp.performPrivateFunction("setMainCanvasVisible:", false)
  • 支持设置画面隐藏的延迟时间（单位：毫秒）。例如 whiteboardApp.performPrivateFunction("setDelayTranslateOut:", 1500)

[0.1.11] - 2025-05-21 ​

  • 新增 Room.setAppExtraOptionsProvider 方法，用于设置应用额外参数。
  • 修复 退出房间时部分数据未正确同步的问题。

[0.1.9] - 2025-04-17 ​

  • 新增 WhiteboardApplication.setWhiteboardTransparent, 实现设置白板透明。

[0.1.8] - 2025-04-11 ​

  • 更新 DSBridge-Android 至 3.0.5。

[0.1.7] - 2025-03-25 ​

  • 修复 RtmSocketProvider 处理消息时的空指针异常。

[0.1.5] - 2025-03-19 ​

  • 新增 RoomRegion, 支持 RoomRegion.PRIVATE 用于私有云部署。

[0.1.4] - 2025-03-14 ​

  • 支持 Android 7.0 及以上版本。

[0.1.1] - 2024-12-06 ​

  • 新增 WhiteboardOptions.maxScaleRatio，实现白板最大缩放比例配置，所有客户端配置必须一致，参数大于等于 1 或为 -1（表示无限制）。
  • 新增 WhiteboardApplication.translateCamera，实现画布平移功能。
  • 新增 WhiteboardApplication.scaleCamera，实现画布缩放功能，以画布中心为固定点。
  • 新增 WhiteboardApplication.resetCamera，实现画布重置功能，缩放比例重置为 1，平移量重置为 [0, 0]。
  • 新增 WhiteboardApplication.enableCameraTranslate，实现控制是否允许通过触摸手势控制相机的缩放和拖动，默认值为 true。
  • 新增 WhiteboardApplication.enableCameraBoundaryHighlight ，实现控制是否允许在相机超出边界时显示警示高亮阴影，默认值为 true。
  • 新增 WhiteboardApplication.setCameraBoundaryColor，实现设置相机超出边界时警示阴影的颜色。

[0.1.0] - 2024-11-27 ​

  • First stable release
