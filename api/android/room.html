Room 模块（Android） ​

Room 是 ScribbleForge SDK 的核心模块之一，负责初始化房间、处理用户进出、应用管理、通信同步、快照恢复等核心功能。

初始化 ​

kotlin
val room = Room(RoomOptions(...))

RoomOptions 参数说明 ​

参数名类型说明
roomIdString房间唯一标识
roomTokenString房间令牌
userIdString当前用户 ID
nickNameString用户昵称
contextContextAndroid 上下文对象
socketProviderSocketProvider实时通信提供者（如 RTM）
windowManagerOptionsWindowManagerOptions?窗口管理器初始化配置
loggerOptionsLoggerOptions?日志配置
extraOptionsMap<String, Any>?其他扩展配置

核心方法 ​

joinRoom ​

加入房间，完成通信连接、状态同步、模块注册等。

kotlin
room.joinRoom(callback)

  • 会自动启动：

    • 通信连接（socketProvider.connect）
    • 应用管理器初始化
    • 窗口管理器初始化
    • 文档同步与快照恢复

leaveRoom ​

退出房间并释放资源。

kotlin
room.leaveRoom()

launchApp ​

启动指定类型的应用程序（如白板、播放器等）。

kotlin
room.launchApp(type, option, appId, callback)
参数类型说明
typeString应用类型标识符
optionApplicationOption启动参数
appIdString?可选应用 ID
callbackRoomCallback<Application>启动结果回调

addListener / removeListener ​

添加或移除房间监听器，用于监听连接状态、错误、用户变化等事件。

kotlin
room.addListener(listener)
room.removeListener(listener)

addAppListener / removeAppListener ​

添加或移除应用层监听器（如应用启动、终止事件）。

kotlin
room.addAppListener(listener)
room.removeAppListener(listener)

内部方法（简要说明） ​

方法名说明
initByVector()基于远程用户进行状态同步
restoreSnapshot()快照恢复操作
sendUpdate()发送 diff 更新数据
sendConflict()处理冲突状态并反馈差异数据

事件回调接口 ​

RoomListener ​

kotlin
interface RoomListener {
    fun onConnectStateChanged(room: Room, state: ConnectionState)
    fun onError(room: Room, error: RoomError)
}

示例代码 ​

kotlin
val roomOptions = RoomOptions(
    roomId = "demo-room",
    roomToken = "TOKEN",
    userId = "user123",
    nickName = "Alice",
    context = context,
    socketProvider = socketProvider
)

val room = Room(roomOptions)

room.joinRoom(object : RoomCallback<Boolean> {
    override fun onSuccess(result: Boolean) {
        Log.d("Room", "Joined successfully")
    }

    override fun onFailure(error: RoomError) {
        Log.e("Room", "Failed to join: ${error.message}")
    }
})
