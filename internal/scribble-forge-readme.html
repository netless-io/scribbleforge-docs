ScribbleForge ​

ScribbleForge is a comprehensive real-time collaborative workspace framework that provides synchronized whiteboarding, media playback, window management, and document viewing capabilities.

Project Structure ​

ScribbleForge/
├── packages/              # Core packages
│   ├── ImageryDoc/        # Image document viewer
│   ├── media-player/      # Synchronized media player
│   ├── room/              # Room management
│   ├── rtm-provider/      # Agora RTM integration
│   ├── slide/             # Slide presentation
│   ├── socketio-provider/ # Socket.IO integration
│   ├── whiteboard/        # Interactive whiteboard
│   └── window-manager/    # Multi-window management
├── example/               # React example application
└── dev/                   # Development utilities

Key Components ​

Room ​

forge-room is the foundation for real-time collaboration. It handles:

  • Room creation and management
  • User session management
  • Application registration and launching
  • Synchronization between clients
javascript
// Example: Room initialization
const rtmProvider = new RTMProvider_2_1(rtmClient);
const room = new Room("roomId", rtmProvider);

// Register applications
room.applicationManager.registerApplication(WhiteboardApplication);

// Join room
await room.joinRoom({
    userId: "userId",
    nickName: "nickName",
    roomToken: "roomToken"
});

Whiteboard ​

forge-whiteboard provides collaborative drawing features:

  • Multiple drawing tools (curve, rectangle, text, etc.)
  • Element selection and manipulation
  • Page management
  • Camera controls (zoom, pan)
  • Sophisticated permission system
javascript
// Example: Launch whiteboard
const whiteboard = await room.applicationManager.launchApplication(WhiteboardApplication, {
    width: 1920,
    height: 1080,
    defaultToolbarStyle: {
        tool: "curve"
    }
}, "MainWhiteboard");

document.body.appendChild(whiteboard.view);

Window Manager ​

forge-window-manager enables multi-window applications:

  • Window positioning and sizing
  • Window state management (normal, minimized, maximized)
  • Focus management
  • Permission system
javascript
// Example: Initialize window manager
const windowManager = await room.applicationManager.launchApplication(WindowManagerApplication, {
    width: 1920,
    height: 1080,
    boxPosition: {
        x: 0.05,
        y: 0.05
    },
    boxSize: {
        width: 0.6,
        height: 0.6
    }
}, "WindowManager");

document.body.appendChild(windowManager.view);

Media Player ​

forge-media-player provides synchronized media playback:

  • Support for video/audio playback
  • YouTube and Vimeo integration
  • Synchronized controls across clients

ImageryDoc ​

forge-ImageryDoc offers image viewing and navigation:

  • Multi-page image viewing
  • Camera controls
  • Permission management

Communication Providers ​

ScribbleForge supports multiple communication channels:

  • rtm-provider: Integration with Agora RTM
  • socketio-provider: Socket.IO integration

Getting Started ​

  1. Install dependencies:
bash
pnpm install
  1. Build packages:
bash
pnpm -r run build
  1. Run the example:
bash
cd example
pnpm run dev

Example Application ​

The example folder contains a React application that demonstrates how to use ScribbleForge components.

Permissions System ​

ScribbleForge implements comprehensive permission systems:

  • Whiteboard permissions: Drawing, editing, deleting, camera control
  • Window Manager permissions: Window creation, manipulation, focus control
  • ImageryDoc permissions: Page navigation, camera control

For example:

javascript
// Add whiteboard drawing permission
whiteboard.permissions.addPermission(WhiteboardPermissionFlag.draw);

// Add window operation permission
windowManager.permissions.addPermission(WindowPermissionFlag.operate);

Building Packages ​

Each package uses esbuild for compilation with a custom Babel plugin:

javascript
// Example build script
esbuild.build({
    entryPoints: ['src/index.ts'],
    bundle: true,
    sourcemap: true,
    outfile: 'dist/package.js',
    format: "cjs"
});
