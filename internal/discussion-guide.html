问题讨论指南 ​

💡 说明
这是一篇引子文章，旨在提供讨论的起点。欢迎大家各抒己见，结合实际情况优化补全。
内容涵盖讨论原则、实践方式、问题分类及示例，开放完善，共同提升决策效率。

背景 ​

在工作中，我们经常会在还没有完整技术方案或代码实践的情况下，就开始关注某个问题，并在信息不足时做决策。这容易导致信息不一致、临时决策、反复讨论等情况。我们希望找到更有效的讨论方式，减少沟通成本，提高决策效率。

有时候，大家对问题的理解不同，或者信息传递不到位，讨论容易卡住，甚至出现情绪化表达，影响效率和结果。讨论的重点是找到合适的方案，更清晰的沟通能帮助大家对齐信息，避免重复讨论，让决策更高效。

并不是所有问题都需要深入讨论，能快速决策的，就尽快定下来，把时间留给更值得推敲的地方。 最终的决定不一定完全符合客户需求，但它应该是团队的一致选择。在信息不完整的情况下，决策可能会有偏差，所以尽可能分析清楚问题，减少试错成本。

方案不会一开始就完美，最终方案也可能还有改进空间。但这不影响我们先做出决定，再在实践中不断优化。

基本原则 ​

  1. 以人为本：相信、尊重、包容、开放
  2. 问题驱动：讨论要围绕明确的问题展开，聚焦目标，避免漫无目的的拉扯。能快速定的就快速定，不要反复纠结。
  3. 悬置决策：如果信息不足，就先不做决定，避免仓促下结论，留出时间让大家思考、补充信息。
  4. 接受不完美：决策可能是错的，但它是当下信息下最合理的选择。承认不完美，持续优化，而不是陷入完美主义的陷阱。

实践 ​

  1. 补全问题信息：
    • 问题描述
    • 方案描述
    • 具体场景
    • 相关问题
  2. 讨论：
    • 同步问题认识
    • 如果能快速决策，直接决策，避免沉浸式讨论
    • 如果存在混淆，可考虑在下班前/第二天再讨论，为大家流出思考时间
  3. 结论：
    • 形成共识
    • 形成决策
    • 形成文档

问题类型 ​

对于以下常见问题，建议优先参考已有决策，避免重复讨论，提升一致性，降低决策成本：

  1. 接口设计

    • 命名规范（接口、字段）
    • 可读性与合理性

  2. 数据处理

    • 数据是否需要同步
    • 数据的存储与传输策略

  3. 性能与优化

    • 可能的性能瓶颈
    • 是否需要优化

WindowManagerOption width/height 或 ratio ​

方案：

  1. width/height
  2. ratio

涉及接口：

  • 外部接口:
    • WindowManagerOption
    • WindowManagerApplication.setRatio(ratio: number)
  • 内部接口:
    • 应用启动参数同步(appParams)
    • 应用内状态同步(window/attrs)

场景/理由：

  1. 白板和多窗口同步： 在多窗口协同场景中，白板应用需要与窗口管理器保持尺寸同步，当前参数传递方式存在两种方案争议。
javascript
// 方案1
room.launchApplication(WhiteboardApplication, {width: 1920, height: 1080});
room.launchApplication(WindowManagerApplication, {width: 1920, height: 1080});

// 方案2
room.launchApplication(WhiteboardApplication, {width: 1920, height: 1080});
room.launchApplication(WindowManagerApplication, {ratio: 16/9});

  1. ratio 需要解释宽高比：

    • width/height 直观易懂
    • ratio 需要额外计算，可能导致误解

  3. 多窗口支持运行时设置ratio：

结论：

  • 协同评估并决策，选定具体方案

WindowManagerOption windowPosition | windowSize | windowSizeRange 是否需要暴露和同步 ​

场景/理由：

  • 尽量不暴露不必要的接口
  • 减少同步数据
    • 同步：通过 AppLanuchParams 中的同步信息，构建 WindowManagerApplication
    • 不同步：通过客户端调用，只在启动时使用参数，支持 Room.addExternalParams，在启动时注入/设置 WindowManagerApplication 属性
